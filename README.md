# Kokoriko Street Grill — version premium

Version améliorée du site Kokoriko.

## Contenu
- 5 pages : accueil, menu, à-propos, contact, panier
- recherche + filtres
- panier localStorage
- formule Frites & Boisson +1 500 FCFA
- commande WhatsApp
- PWA avec service worker versionné
- identité visuelle alignée sur le logo fourni
- fond blanc/ivoire + noir + orange Kokoriko
- loader de marque uniquement à la première ouverture de la session
- micro-interactions et effets de survol
- responsive desktop/tablette/mobile
- prise en charge de `prefers-reduced-motion`

## Médias
Le logo original est conservé dans `assets/logokok.webp`.
La version recadrée utilisée dans l'interface est `assets/logokok-cropped.webp`.
Les icônes PWA sont `assets/icon-192.png` et `assets/icon-512.png`.

Voir `CHARTE-EDITORIALE-GRAPHIQUE.md` pour la direction de marque.
