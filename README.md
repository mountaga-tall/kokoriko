# Kokoriko V2

Version fusionnée et corrigée du site Kokoriko.

- 5 pages : accueil, menu, à propos, contact, panier
- recherche + filtres
- panier localStorage
- formule Frites & Boisson +1500 FCFA
- commande WhatsApp
- PWA avec cache/versioning
- aucune dépendance Tailwind CDN

Le fichier `assets/logokok.jpeg` est volontairement facultatif : s’il est ajouté, il remplace automatiquement le monogramme K dans le logo.
